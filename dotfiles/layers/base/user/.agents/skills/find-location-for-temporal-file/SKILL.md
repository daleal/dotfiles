---
name: find-location-for-temporal-file
description: Use when you want to decide where to save a temporal file. Always use this skill before saving a temporal file.
---

You should store temporal files in the `./tmp` directory. This ensures they are saved in a temporary location where you have permission to write, that is easy to access and manage. Inside this directory, create subdirectories as needed to organize temporal files by project or context.
