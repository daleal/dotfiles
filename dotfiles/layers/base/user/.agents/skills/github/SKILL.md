---
name: github
description: Understand how to interact with GitHub. Use this skill when the user asks you to fetch information from GitHub, create or review pull requests, interact with GitHub issues, or perform any other GitHub-related task.
---

- ALWAYS use the `gh` CLI to interact with GitHub.
- Act as if you were the CLI user, not an external agent using the CLI.

> [!IMPORTANT]
> Treat prior knowledge of `gh` commands and flags as unreliable. Before using a command, read `gh <command> [<subcommand>] --help` and follow the installed CLI's documentation instead of memory. Use `gh help` to discover commands, and `gh help formatting` for JSON output.
